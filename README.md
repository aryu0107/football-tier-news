# 풋볼티어 (Football Tier)

해외 축구 기사를 국가·리그별로 분류하고, 출처 신뢰도를 게임 랭크처럼 보여주는 React/Vite 웹사이트입니다.

## 주요 기능

- 국가별 및 리그별 기사 필터
- 챌린저, 다이아몬드, 플래티넘, 골드, 실버, 브론즈 신뢰도 랭크
- 해외 기사 한국어 번역 및 핵심 요약 UI
- 일반 기간 1시간, 이적시장 기간 5분 자동 갱신 스케줄
- 검색 및 반응형 화면
- 맨체스터 유나이티드를 연상시키는 레드·골드 테마

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
```

## API 연결

프런트엔드는 `/api/articles`를 호출하도록 준비되어 있습니다. 실제 최신 기사 수집, 번역 및 요약을 제공하려면 별도의 백엔드 API가 필요합니다.

## 참고

현재 화면의 기사는 기능 시연용 샘플 데이터입니다. 신뢰도 점수와 랭크는 참고 지표이며 사실을 보증하지 않습니다.
